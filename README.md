# Assigment2

Fetch + Array Methods

Detta är min inlämningsuppgift i kursen 

# Vad programmet gör

Koden hämtar data från "TheMealDB API" (ett öppet API med matrecept)  
och använder sedan olika array-metoder för att analysera datan.

Jag skriver bara ut allt i "konsolen (F12 → Console)" eftersom uppgiften inte kräver något grafiskt gränssnitt.



Funktioner som demonstreras

Array-metoder:
- `map`  
- `filter`  
- `reduce`  
- `sort`  
- `slice`  
- `some`  
- `every`  
- `flatMap`

Vad som skrivs ut:
1. De första 5 måltiderna i alfabetisk ordning (bara namnen)  
2. Alla måltider i en viss kategori (namn + kategori)  
3. Antal måltider per kategori  

Sedan har jag lagt till några "stretch-grejer":
- Gruppar måltider efter kategori (groupBy)
- Gör små “sammanfattningsobjekt” med namn + ingredienser
- Räknar hur ofta olika ingredienser förekommer



Hur man kör

1. Klona eller ladda ner projektet.  
2. Öppna mappen i "WebStorm"
3. Öppna `index.html` i webbläsaren (gärna via Live Server eller “Debug” i WebStorm).  
4. Öppna Console (F12 → Console).  
5. Kolla loggarna där då allt resultat skrivs ut dit.
